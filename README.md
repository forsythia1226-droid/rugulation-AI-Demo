# 사내규정 AI 에이전트 · 파일럿

대한전선 사내 AI 에이전트 구축 사례 대회 출품 데모입니다.

사내규정을 게시판에서 내려받아 Ctrl+F로 찾던 과정을, 질문 한 번으로 줄이는 AI 창구입니다.
답변마다 근거 조문이 표시되고, 오른쪽 규정 원문에서 해당 문장이 바로 하이라이트됩니다.

## 주요 기능

- 어느 규정인지 몰라도 되는 통합 질문 → 소관 규정 자동 판단
- 답변 근거 조문의 원문 위치 하이라이트
- 여러 규정에 걸친 질문은 관련 규정으로 이어서 안내
- 규정 주관부서가 직접 작성하는 해석 지침
- AI가 답하지 못한 질문의 주관부서 확인 요청

## 안내

- 규정 목록과 업무분류는 사내규정 관리규정 제11조를 따릅니다.
- **조문 본문은 시연을 위해 작성한 가상 조문이며 실제 사규가 아닙니다.**
- 운영 전환 시 사내망에 설치하고 사내 승인 LLM을 연결하는 것을 전제로 합니다.
